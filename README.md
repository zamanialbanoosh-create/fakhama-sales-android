# Fakhama Sales Android

Tablet-first Android point-of-sale and order-entry app for Taj Al Fakhama.

## V0.1
- Native Android / Kotlin / Jetpack Compose
- Arabic RTL interface
- Landscape tablet layout
- Large touch targets for fast counter use
- Product/service selection
- Live cart quantities and KWD totals
- Annual VIP package entry point

## Planned next
1. Customer mobile lookup/create
2. Fabric and dishdasha configuration wizard
3. Measurements and tailor assignment
4. Discounts and VIP balance
5. Invoice persistence
6. Thermal printing
7. WhatsApp order/invoice handoff
8. Offline-first local storage and server synchronization
